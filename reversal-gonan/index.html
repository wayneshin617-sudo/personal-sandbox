제1화　두 얼굴의 누명

졸라 노잼이던 추리를, 공판으로 뒤집는다.

증거로 증언을 부숴. 아니면 무명한만 감옥 간다.

재판 기록

    항목을 선택하세요

    모순이 보이는 증언에 증거를 들이밀면 공판이 뒤집힙니다.

    조작법

    클릭 / Z / Space / Enter — 대사 진행

    조사 — 반짝이는 지점을 눌러 단서를 줍니다.

    기다려! — 증언을 추궁. 페널티 없음. 전부 눌러보세요.

    이의 있음! — 지금 문장과 모순되는 증거를 제출.

    기록 / R — 증거와 인물 확인.

    틀린 증거를 제출하면 재판장의 인내심이 깎입니다. 5번 실패하면 유죄.
