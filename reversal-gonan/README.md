# 역전고난 — 제1화 「두 얼굴의 누명」

명탐정 고난을 **역전재판식 공판 어드벤처**로 다시 만든 웹 게임입니다.

원본이 노잼이었던 지점은 클릭만 하면 끝나는 추리였습니다. 이번 판은 증언을 추궁하고, 모순에 증거를 들이밀어야 재판이 뒤집힙니다. 틀리면 인내심이 깎이고, 5번 실패하면 무명한은 징역 15년입니다.

## 실행

`reversal-gonan` 폴더에서 로컬 서버를 띄운 뒤 `index.html`을 엽니다.

```bash
cd reversal-gonan
python3 -m http.server 8765
```

브라우저에서 http://127.0.0.1:8765 로 접속하세요.

법정 퍼즐만 연습하려면: http://127.0.0.1:8765/?court=1

## 조작

| 입력 | 동작 |
| --- | --- |
| 클릭 / Z / Space / Enter | 대사 진행 |
| 반짝이는 지점 | 조사 |
| 기다려! / A | 증언 추궁 (페널티 없음) |
| 이의 있음! / S | 증거 제출 |
| 기록 / R | 재판 기록 |

## 레거시

- **시스템:** 역전재판 — 조사 / 심문 / 기다려 / 이의 있음 / 인내심 게이지
- **캐릭터·톤:** 명탐정 고난 — 마취총, 슬라이딩, 먹튀, 말도 안 되는 수법이 사실이었던 그 결
- 스프라이트·BGM은 원작 에셋이 아니라 이 게임용으로 새로 그렸습니다.

## 스포일러: 공략

1. 사무소 서랍에서 **마취총**, 구치소에서 **무명한의 혹**, 박물관에서 **부검 결과**와 **거꾸로 된 발자국**. CCTV나 하네스(또는 연구소 장부) 중 하나.
2. 경비 증언 4번 「발자국이 없다」에 **거꾸로 된 발자국**. 천장 창 문장은 추궁하면 추가됨.
3. 감식 「둔기 타살」에 **부검 결과**. 「몽둥이 혈흔」에는 혹/마취총도 통함.
4. 전도만 「집에 있었다」에 **CCTV**, 또는 물구나무 문장을 추궁한 뒤 추가된 행글라이더 문장에 **하네스/장부**.
5. 마지막 선택: 물구나무 침입 → 심장사 → 행글라이더 탈출.
