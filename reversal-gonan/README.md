# 명탐정 고난 — 제1화 「두 얼굴의 누명」

명탐정 코난 에피소드 구조(현장 → 헛추리 → 마취 → 조사 → 전원 집합 → 「범인은 바로 너야」)로 만든 웹 추리 게임입니다. 주인공 고난 성은 원피스 찰로스 성 디자인 그대로입니다.

클릭만 하면 끝나는 추리가 아니라, 증언을 추궁하고 거짓말에 증거를 들이밀어야 진실이 열립니다. 5번 실패하면 무명한은 연행됩니다.

## 실행

`reversal-gonan` 폴더에서 로컬 서버를 띄운 뒤 `index.html`을 엽니다.

```bash
cd reversal-gonan
python3 -m http.server 8765
```

전원 집합 퍼즐만 연습하려면: `?gather=1` (구 주소 `?court=1`도 동일)

## 조작

| 입력 | 동작 |
| --- | --- |
| 클릭 / Z / Space / Enter | 대사 진행 |
| 반짝이는 지점 | 조사 |
| 거짓말이다! / A | 증언 추궁 (페널티 없음) |
| 진실은! / S | 증거 들이밀기 |
| 기록 / R | 사건 기록 |

## 레거시

- **스토리:** 명탐정 코난 — 밀실, 가짜 다잉메시지, 전원 집합, 트릭 해설
- **주인공 비주얼:** 세계귀족 찰로스 성 (방울 헬멧, 펌, 금장 흰옷, 마취 권총)
- 스프라이트·BGM은 원작 에셋이 아니라 이 게임용으로 새로 그렸습니다.

## 스포일러: 공략

1. 미술관에서 **혈흔 글씨**, **부검 메모**, **빗장**, **낚시줄**. 별장 소파에서 기절한 무명한, 서랍에서 **마취 권총**. CCTV·출입 명단·위작 장부 중 하나.
2. 경비 증언 「밀실」에 **빗장/낚시줄**. 「8시 30분 퇴장」을 추궁하면 추가되는 찰칵 소리에 **CCTV/낚시줄**.
3. 감식 「다잉메시지」에 **부검 메모**. 「범인은 무명한」에는 마취 권총/혹.
4. 전도만 「집에 있었다」에 **CCTV**, 「낚시 취미 없음」을 추궁한 뒤 **낚시줄/장부**, 「진품만」에 **위작 장부**.
5. 마지막 선택: 문틈으로 낚시줄을 걸어 밖에서 빗장을 잠갔다.
